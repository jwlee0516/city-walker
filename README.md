City Walker is a minimalist 2D side-scrolling experience set in a neon-lit urban nightscape.

Step into a glowing city where movement, atmosphere, and visual rhythm take center stage. Designed as a focused exploration of player feel and environment, the game emphasizes smooth horizontal traversal and immersive lighting over complex mechanics.

This project is part of my journey into game development, built entirely in Unity as a solo prototype.

🎮 Controls
A / D — Move
Shift — Dash

🌃 Features
Neon-inspired pixel art environment
Smooth and responsive movement system
Layered parallax city background
Stylized lighting and glow effects

🛠️ Built With
Unity (URP)
Custom pixel art assets

📌 Notes
This is an early prototype (v0.1). More features, interactions, and polish are planned.
